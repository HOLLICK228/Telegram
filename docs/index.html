GlassGram

Неофициальный клиент Telegram с настройкой оформления чата «Liquid Glass». Матовый или глянцевый стиль включается в Настройки → Настройки чата.

Что внутри

  • Настройка «Liquid Glass» в настройках чата: выкл / матовое / глянцевое
  • Размытие фона под пузырями и панелью ввода
  • Всё остальное работает как в обычном Telegram

GlassGram — независимый мод на основе открытого кода Telegram для Android. Не связан с Telegram FZ-LLC. Вход выполняется через официальные серверы Telegram. Исходный код мода открыт по лицензии GPLv2.
